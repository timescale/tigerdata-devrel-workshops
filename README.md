# Tiger Data Workshops

Hands-on, run-it-yourself workshops from the Tiger Data Developer Relations team. Pick one
and open it in GitHub Codespaces — you don't need to install anything.

## Workshops

### [Sensor to Insight](https://github.com/timescale/sensor-to-insight-workshop)

Build a real-time IoT analytics pipeline on Tiger Cloud from scratch. Hypertables, columnar
compression, continuous aggregates, `time_bucket()`, and retention policies. You write the
SQL and walk away with a working service you built yourself.

*60 minutes · beginner-friendly · no prior time-series experience needed*

### [MQTT to Dashboard](https://github.com/timescale/mqtt-grafana-workshop)

Stream manufacturing sensor data from an MQTT broker into Tiger Cloud and put a Grafana
dashboard on top of it. An end-to-end IIoT pipeline, built live.

*60 minutes · some Python helps, but it's all provided*

### [Fork, Break, Fix, Delete](https://github.com/timescale/fork-break-fix-delete-workshop)

Point a coding agent at a database it's allowed to break. Wire Tiger MCP into Claude Code,
Codex or Copilot, fork a service into an instant isolated copy, turn the agent loose on a
deliberately terrible schema, measure the fix, and throw the fork away.

*60 minutes · bring your own coding agent · intermediate*

## What you need

- **A Tiger Cloud account.** Each workshop's README has a signup link with trial credit.
- **A GitHub account**, for Codespaces. Every workshop opens from a badge in its own README
  with the tooling pre-installed.
- **An hour**, plus about twenty minutes of setup beforehand. Do the setup the day before —
  workshop day is a bad time to debug a login.

That's it. No local database, no drivers, nothing to install.

## Attending one live?

These are run as live virtual workshops, and each repo's README is written so you can also
work through it entirely on your own afterwards. Every step is self-contained, so falling
behind during a live session doesn't lock you out of the next one.

## Questions
